# 短剧剧本创作

## 概述

从题材与目标受众出发，产出可直接拍摄的竖屏短剧剧本：世界观 → 分集大纲 → 场景与台词。核心原则：每集必须有钩子（开头 3 秒冲突）与结尾悬念。

## 使用步骤

1. **确认输入**：向用户确认题材（逆袭/复仇/甜宠/悬疑）、总集数、单集时长（默认 60-90 秒）、主角人设。缺省时给出默认方案并说明。
2. **搭建结构**：先写一句话故事核（谁 + 想要什么 + 被什么阻挡 + 反转是什么），再列分集大纲，每集一行：冲突 → 升级 → 钩子。
3. **套用模板**：需要完整剧本格式时，读取附带模板 `templates/script-template.md`，按模板填充场景头、动作描写、台词。仅在进入逐集写作阶段才读取，不要提前加载。
4. **逐集写作**：每集 8-15 句台词；动作描写用现在时、可拍摄的具体动作；避免旁白交代剧情。
5. **自检**：完成全部集数后运行附带脚本做格式与节奏检查：

   ```bash
   python scripts/check.py <剧本文件.md>
   ```

   脚本检查：场景头格式、每集台词数量、是否缺少结尾钩子标记。仅在自检阶段运行。
6. **交付**：输出剧本文件路径 + 分集大纲摘要，询问用户是否需要调整某一集。

## 常见错误

| 错误 | 修正 |
|------|------|
| 开头用大段背景介绍 | 第 1 句台词就进入冲突 |
| 台词书面化、长句 | 口语短句，单句不超过 25 字 |
| 结尾平淡收场 | 每集最后一行必须是悬念或反转 |

## 与相邻 skill 的边界

- 已有剧本、只改台词措辞/口语化/人设语气 → 用 `short-drama-dialogue-polish`
- 本 skill 负责"从无到有"，包括新增场景与剧情
