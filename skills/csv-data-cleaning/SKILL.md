# CSV 数据清洗

## 概述

把脏 CSV 清洗成可分析的干净文件。核心原则：原始文件只读不改，所有清洗规则先列清单经用户确认，再批量执行，全程可追溯。

## 使用步骤

1. **体检**：读取文件前 20 行与总行数，统计每列的空值率、重复行数、类型混杂情况（如日期列混有 `2026/1/2` 与 `Jan 2, 2026`）。
2. **列清洗规则清单**：向用户输出「列名 → 问题 → 拟处理规则」表格，例如：
   - `order_date`：格式混杂 → 统一为 `YYYY-MM-DD`，无法解析的行标记而非删除；
   - `amount`：含千分位与货币符号 → 转 float；
   - 全空列 → 建议删除，需确认。
3. **确认后执行**：用 pandas 按确认后的规则处理；默认策略：
   - 完全重复行去重，保留首条；
   - 缺失值不擅自填充，按列规则处理（数值列可留空，关键键列缺失的行移入异常文件）；
   - 列名转 snake_case。
4. **双文件输出**：干净数据写入 `<原名>_clean.csv`，被剔除/无法解析的行写入 `<原名>_rejected.csv` 并附 `reason` 列。绝不覆盖原文件。
5. **交付报告**：报告输入行数、输出行数、剔除行数及原因分布、每列空值率前后对比。

## 常见错误

| 错误 | 修正 |
|------|------|
| 直接覆盖原文件 | 永远输出新文件，原文件只读 |
| 静默丢弃异常行 | 异常行进 rejected 文件并写明原因 |
| 用 0 填充所有缺失值 | 缺失策略逐列确认，不默认填 0 |
