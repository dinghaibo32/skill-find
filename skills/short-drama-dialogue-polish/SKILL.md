# 短剧台词改写

## 概述

对**已有剧本**的台词做定向改写，不新增剧情、不改动场景结构与分集大纲。核心原则：改写前后剧情信息量不变，只改表达方式。

## 使用步骤

1. **获取原稿**：让用户提供剧本文件或粘贴待改段落。确认改写范围（全剧/某集/某段）与目标风格（更口语/更狠/更甜/更符合某角色人设）。
2. **提取台词清单**：逐行列出原台词，标注角色。跳过动作描写与场景头——它们不在本 skill 职责内。
3. **逐句改写**，遵守规则：
   - 单句不超过 25 字，长句拆成短句或反问；
   - 书面词换口语词（"因此"→"所以"，"质问"→"你凭什么"）；
   - 保留原句的剧情信息（人物关系、关键事实、伏笔），不得增删情节；
   - 贴合角色说话风格：强势角色用命令句/反问，隐忍角色用短句/停顿。
4. **对照输出**：以「原句 → 改句」对照表交付，方便用户逐条取舍；用户确认后再生成替换后的完整剧本。
5. **边界检查**：若用户实际想要新增场景、改剧情走向或从零写剧本，明确告知并转用 `short-drama-script`，不要在本 skill 内扩写剧情。

## 常见错误

| 错误 | 修正 |
|------|------|
| 顺手改了剧情或加了新角色 | 只动台词文本，剧情信息保持等价 |
| 所有角色改成同一种语气 | 按人物表逐角色区分说话风格 |
| 直接覆盖原稿 | 先给对照表，确认后再替换 |
